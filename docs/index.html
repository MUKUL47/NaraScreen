SCRIPTS & API

Describe it, or let your AI write it

One JSON file says what to click and what to say. NaraScreen records a real browser, generates the voice and renders every effect. It takes timestamps and coordinates off your hands.

narascreen validate demo.json   # instant
narascreen check    demo.json   # dry run, no recording
narascreen make     demo.json   # the video

Or run narascreen serve and drive it over HTTP.

For AI agents

Tell your assistant what video you want and point it at NaraScreen. The server publishes everything an agent needs:

editor/bin/narascreen serve          # http://127.0.0.1:4790
curl http://127.0.0.1:4790/llms.txt  # start here: short, for LLMs
curl http://127.0.0.1:4790/docs.md   # the full manual
curl http://127.0.0.1:4790/v1/schema # JSON Schema of the demo script

The agent writes the script, validates it, dry-runs it and makes the video. Every answer is one JSON envelope with ok, error.code and a hint. You can edit the script yourself at any time: text changes re-render without re-recording.

Everything stays on your machine

The browser, the voices (Kokoro, in Docker) and the rendering (FFmpeg) all run locally. The HTTP server binds to 127.0.0.1 by default. No accounts, no uploads, no watermarks.
